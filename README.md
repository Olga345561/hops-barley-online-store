# Hop & Barley 🍺

**Hop & Barley** — це веб-додаток та інтернет-магазин для любителів і професіоналів домашнього пивоваріння. Проєкт містить каталог товарів, рецепти, інструкції для пивоваріння, а також систему замовлень і ком'юнити.

## 🛠 Технології в проєкті
* **Backend:** Python, Django, Django REST Framework, GraphQL (Graphene)
* **Database:** PostgreSQL
* **Containerization:** Docker, Docker Compose
* **Server:** Gunicorn

## 🚀 Як запустити проєкт через Docker (Рекомендовано)

Для запуску проєкту у вас мають бути встановлені **Docker** та **Docker Compose**.

1. Клонуйте репозиторій або відкрийте проєкт на своєму комп'ютері.
2. Створіть файл `.env` на основі `.env.example` та заповніть необхідні змінні середовища.
3. Запустіть контейнери за допомогою команди:

## 💻 Локальний запуск (Без Docker)

1. Створіть та активуйте віртуальне середовище:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

Встановіть залежності:
```bash
pip install -r requirements.txt
```

2. Виконайте міграції бази даних:
```bash
python manage.py migrate
   ```
3. Запустіть локальний сервер:
```bash
python manage.py runserver
```
### Щоб створити суперкористувача (адміністратора), виконайте такі кроки через термінал:

Якщо ваш проєкт зараз працює в Docker, виконайте команду:

```bash
docker compose exec web python manage.py createsuperuser
```
Якщо ви запускаєте проєкт локально без Docker, просто введіть: 
```bash
python manage.py createsuperuser
```
* Система по черзі попросить вас ввести:

1. Email (адреса електронної пошти).

2. Password (пароль — під час введення символи не відображатимуться заради безпеки).

3. Password (again) (повторіть пароль для підтвердження).

### Як зайти в адмін-панель
Переконайтеся, що ваш проєкт запущений (у Docker або через локальний сервер).

Відкрийте браузер і перейдіть за адресою:
[http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)

Введіть створені на попередньому кроці Email та Password, після чого натисніть кнопку входу.

### Як зайти в статистику / інтерфейс GraphQL
Оскільки у вашому проєкті використовується GraphQL (schema.py), для тестування запитів та перегляду документації зазвичай використовується спеціальний веб-інтерфейс (GraphiQL).

Перейдіть у браузері за стандартною адресою GraphQL-ендпоінту вашого проєкту (залежно від налаштувань у config/urls.py):
(http://127.0.0.1:8000/admin/orders/order/store-analytics/)

Якщо у вас підключено інтерактивний графічний інтерфейс (GraphiQL), перед вами відкриється сторінка з віконцем для написання запитів (Query), документацією праворуч та кнопкою запуску.
